{%- comment -%} An email link that keeps the address out of the page's code, to protect it from spam bots. The page only contains the two halves of the address; assets/js/dyn-email.js joins them into a working mailto: link once the page has loaded. Shown text uses " [at] " instead of "@". Params: address - the email address (required) class - CSS class for the link (optional) label - accessible name / tooltip (optional, default "Email") show - true to show the address as text ("name [at] domain") after the icon/content icon - Font Awesome classes for an icon (optional) {%- endcomment -%} {%- assign email_parts = include.address | split: "@" -%} {%- if include.icon -%}{%- endif -%} {%- if include.show -%}{{ email_parts[0] }} [at] {{ email_parts[1] }}{%- endif -%}
